# Result Audit

Date: 2026-07-04

## Decision

Use `quality_fusion` as the current accepted synthetic smoke model.

Use `fixed_fusion` as the current accepted accuracy model for the real P1-HHAR embedding bridge.

Use `proxy_decision_fusion` only for the calibration/reliability tradeoff result, not as the headline accuracy model.

Use `p1_hhar_signal_quality` as the preferred quality-target source for reliability/error-awareness analysis, because it is grounded in the real HHAR sensor windows.

Do not use these variants as headline results yet:

- `proxy_quality_fusion`
- `proxy_decision_fusion`
- `posthoc_proxy_fusion`
- `quality_hard_tuned` with `quality_power: 2.0`

Reason: they improve selected degradation slices, but they do not beat `fixed_fusion` consistently on aggregate macro-F1.

## Rejected Improvement Attempts

### Proxy quality fusion

Using target/proxy quality directly inside feature-level fusion did not improve aggregate test macro-F1.

### Decision-level proxy fusion

Decision-level fusion helped a few degradation slices, especially conflict/frame-drop/delay, but worsened aggregate ECE and NLL.

### Post-hoc proxy gating

Post-hoc proxy gating helped selected slices, but average degradation delta remained negative.

### Strong quality gating

`quality_power: 2.0` over-weighted high-quality modalities and reduced aggregate macro-F1.

## Current Claim Boundary

Safe claim:

P3 provides a runnable signal-quality-aware fusion and degradation benchmark. On smoke synthetic data, learned quality-aware fusion improves macro-F1 and calibration metrics. On harder synthetic data, it mainly improves calibration/reliability metrics and reveals degradation regimes where naive quality gating can fail. On the real P1-HHAR embedding bridge, fixed fusion is the best macro-F1 model, while decision-level proxy fusion gives a clear calibration/reliability tradeoff. Real signal-quality grounding improves quality/error AUROC and makes low-quality slices measurable.

Unsafe claim:

Quality-aware fusion universally improves macro-F1 across synthetic or real degradation regimes.
